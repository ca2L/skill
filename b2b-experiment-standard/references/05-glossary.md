# 术语与写法

> 本文件统一中英文术语、缩写和易混概念。写作时优先用中文术语，必要时在括号里保留英文，避免同一文档反复切换。

## 1. 实验对象与设计

| 术语 | 英文/缩写 | 一句话定义 | 常见误用 |
|---|---|---|---|
| 实验单元 | randomization unit | 被随机分配到 treatment/control 的最小实体，如企业、账户、商家、区域、时段 | 把“用户”当默认单元，忽略企业/合同层 |
| 企业/账户 | account / company | B2B 的采购主体；一个企业可有多个子账户、联系人、收货地址 | 把登录用户数当企业数 |
| 集群 | cluster | 共享干预或结果相关的一组单元，如一个商家下的买家、一个区域内的门店 | 随机在集群、分析在个体，却不做 cluster-robust |
| 切换实验 | switchback | 按时间片交替 treatment/control，控制供给、库存、区域政策的干扰 | 忽略时间趋势和 carryover |
| 区域实验 | geo test | 以市场/城市/区域为单元随机，适合定价、营销、履约政策 | 市场数太少却按个体样本量算功效 |
| 曝光 | exposure | 单元真正进入实验干预的状态；分配 ≠ 曝光 | 用“分配数”冒充“曝光数” |
| 分流 | assignment / split | 按哈希或分层把单元分到各臂 | 分流比例与预注册不一致却不报 SRM |
| 互斥 | mutual exclusion | 同一单元不能同时进入互相干扰的实验 | 只做“实验层”不做业务冲突检查 |
| 预注册 | pre-registration | 曝光前冻结主指标、窗口、总体、估计量、子群、阈值 | 看完数据再补“我们本来就想看这个” |
| 修订 | amendment | 预注册后任何实质性改动，需记录时间、原因、影响 | 把修订藏起来，伪装成原计划 |

## 2. 数据质量

| 术语 | 英文/缩写 | 一句话定义 | 常见误用 |
|---|---|---|---|
| 样本比例失衡 | SRM, sample ratio mismatch | 实际分流比例与计划比例显著不符，通常用卡方检验 | p=0.01 就重加权“修好”，不查分流 bug |
| 标准化均值差 | SMD, standardized mean difference | 两组协变量均值差除以合并标准差；常用 `abs(SMD) < 0.10` | 只做 t 检验显著性，不看实际不平衡 |
| 曝光完整性 | exposure completeness | 应曝光单元中实际记录到曝光的比例，以及各臂差异 | 只看总曝光率，不分平台/天/臂 |
| 污染 | contamination | 对照组接触 treatment，或 treatment 组接触对照机制 | 只查“是否点过”，不查客服、线下、跨设备 |
| 重复账户 | duplicate account | 同一企业/主体被拆成多个账户，导致单元不独立 | 只按账户 ID 去重，不按企业主体/税号/域名 |
| 数据血缘 | lineage | 指标从源表到报表的字段级路径、刷新时间、对账差异 | 只写“来自数仓”，无法追到字段和 SQL |
| 数据质量门禁 | DQ gate | 读数前必须通过的 S1/S2/S3 检查 | 把 S1 当“建议”，带着 SRM 读主指标 |

## 3. 指标

| 术语 | 英文/缩写 | 一句话定义 | 常见误用 |
|---|---|---|---|
| 北极星指标 | North Star | 业务长期价值的单一锚点，不一定是实验主指标 | 每个实验都拿 GMV 当北极星，忽略护栏 |
| 主指标 | primary metric | 预注册的、决定实验成败的单一指标 | 同时设 5 个主指标，事后挑显著的 |
| 次要指标 | secondary metric | 解释机制、支持决策的辅助指标 | 把次要指标显著当成主结论 |
| 护栏 | guardrail | 不能被实验伤害的指标，带 owner、阈值、熔断动作 | 只监控不否决，或没有 owner |
| 指标口径 | metric definition | 总体、分子/分母、窗口、单位、过滤、去重、币种/税率 | 同名指标不同 SQL，跨团队不可比 |
| 报价到订单 | Q2O, quote-to-order | 从询价/报价到订单的转化率，B2B 核心漏斗 | 把“报价数”当“询盘数”，分母不一致 |
| 净 GMV | net GMV | 扣除取消、退款、退货、虚假订单后的成交额 | 用下单 GMV 代替净 GMV |
| 报价接受率 | quote acceptance rate | 买家接受报价的比例，常按报价单/企业去重 | 按报价行数算，忽略一单多行 |
| 按时履约率 | on-time fulfillment | 在承诺时效内完成发货/交付的订单占比 | 只看出库时间，不看承诺口径 |
| 买家/商家留存 | buyer/seller retention | 观察窗口内再次下单/再次活跃的企业或商家比例 | 用登录留存替代交易留存 |

## 4. 统计

| 术语 | 英文/缩写 | 一句话定义 | 常见误用 |
|---|---|---|---|
| 意向治疗效应 | ITT | 按最初随机分组分析，不管是否曝光/依从 | 用曝光组替换随机组，破坏因果 |
| 处理组效应 | TOT / LATE | 对“实际接受处理”的单元估计的效应 | 把 TOT 当全体效应汇报 |
| 条件平均处理效应 | CATE | 给定协变量/子群下的效应 | 把探索性子群差异当预注册结论 |
| 最小可检测效应 | MDE | 给定 α、power、样本量能稳定检出的最小效应 | 实验后拿观测效应反推“我们本来就能测到” |
| 统计功效 | power | 真实效应存在时检出它的概率，常用 80% | 只算样本量，不算 cluster DEFF/流失 |
| 设计效应 | DEFF | 聚类设计相对个体随机导致的方差膨胀，`1 + (m-1)ICC` | 随机在商家、分析在订单，却按个体算 |
| 聚类稳健标准误 | cluster-robust SE | 允许同一 cluster 内误差相关的标准误 | 用普通 t 检验处理商家/区域聚类 |
| 双重差分 | DID | 比较 treatment/control 的前后变化差，控制共同趋势 | 不检查平行趋势就下因果结论 |
| 合成控制 | synthetic control | 用多个未处理单元加权构造对照，适合单一大市场/大商家 | 权重外推、donor 池受污染 |
| 中断时间序列 | ITS | 用干预前后时间序列的水平/斜率变化估计效应 | 忽略季节性和同期其他政策 |
| 序贯检验 | sequential test | 在多次 peek 下控制整体 α 的方法 | 每天看 p 值，p<0.05 就停 |
| 贝叶斯实验 | Bayesian A/B | 用后验概率/期望损失做决策 | 把“95% 概率优于对照”当频率派 p 值 |
| 多重比较 | multiple testing | 对多个指标/子群/臂控制错误发现率或族错误率 | 只对主指标校正，子群随便看 |
| BH / Holm | Benjamini–Hochberg / Holm | 常见的 FDR / FWER 校正方法 | 对相关指标机械校正，或完全不校正 |
| 方差削减 | CUPED | 用预前期协变量调整结果，降低方差；削减约 `ρ²` | 写成 `1 − ρ²`，或用实验期变量做调整 |

## 5. 决策与治理

| 术语 | 英文/缩写 | 一句话定义 | 常见误用 |
|---|---|---|---|
| 最小业务期望 | MBE, minimum business expectation | 低于它就不值得全量的效应门槛 | 只看统计显著，不看业务门槛 |
| 全量 | full rollout | 把 treatment 推给全部目标人群 | 不做灰度、不留 holdout |
| 定向 | targeting | 只对预注册的、效应证据足够的子群上线 | 用探索性子群事后定向 |
| 迭代 | iterate | 保留方向、修正机制/护栏后再测 | 把“再试一次”当决策，不写修改点 |
| 停止 | stop | 终止当前版本，不再扩大 | 因一次不显著就永久放弃方向 |
| 复测 | retest | 用新设计/新样本回答未决问题 | 同一数据反复切片直到显著 |
| 保留组 | holdout | 全量后仍保留 5–10% 未处理人群，用于长期评估 | 全量后没有任何对照 |
| 实验卡 | experiment card | 一页纸记录问题、设计、结果、决策、复用点 | 只有截图和群聊结论 |

## 6. 写作约定

- 数字统一：比例写 `8.4%`，百分点写 `+0.8pp`，相对提升写 `+9.52%`；不要混用“百分比”和“百分点”。
- 区间统一：`95% CI [下限, 上限]`，并注明是绝对还是相对。
- 样本统一：写“每臂分析样本”，不要只写总样本。
- 结论统一：先写“证据”，再写“决策”，最后写“限制”；不要用“显著”代替“值得做”。
- 中英文统一：首次出现写“中文（English）”，后文只用中文；字段 ID 保留英文，如 `D02`。
