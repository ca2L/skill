# 统一案例：报价 SLA（企业级 A/B）

> 本文件是包内**唯一**的完整运行案例。所有文档引用同一套样本量、效应、CI 和 p 值；不要在其他文件里另造一套数字。
> 旧版“6,200 家企业/臂、+9.4%、p=0.012”的写法已废弃，原因是它与 8.4%→9.2% 的效应和样本量不自洽。

## 1. 业务背景

平台的中型企业买家在提交询价后，常因卖家报价慢而流失。业务想验证：把卖家报价承诺从 24 小时缩短到 4 小时，并加入超时升级，是否能让更多询价转成订单。

**决策问题**：如果 Q2O 提升且卖家侧不受伤，是否全量？如果 Q2O 提升但卖家报价率下降，是否迭代？

## 2. 设计

| 项目 | 设定 |
|---|---|
| 实验单元 | 企业/账户（company_id），同一企业多账号合并 |
| 分流 | 50/50，按 company_id 哈希，按行业/规模分层 |
| 样本 | 计划 16,000 家企业/臂；实际分析 16,000 vs 15,850 |
| 周期 | 30 天主窗口；7/14/30 天累计读数 |
| 主指标 | Q2O（询价后 30 天内下单的企业比例） |
| 次要指标 | 报价接受率、客单价、净 GMV、新买家 Q2O |
| 护栏 | 卖家报价率（阈值 −5pp）、取消率（阈值 +2pp）、纠纷率（阈值 +0.5pp） |
| 设计参数 | baseline 8.4%，相对 MDE 11%，α=0.05，power=0.80 |
| 最小样本 | 14,847 家/臂；计划 16,000 家/臂，实际 MDE 10.59% |
| 分析总体 | ITT：所有被分配企业；曝光/TOT 作次要 |
| 估计量 | 企业层比例差；cluster-robust（企业为 cluster） |

## 3. 数据质量

| 检查 | 结果 | 判定 |
|---|---|---|
| SRM：16,000 vs 15,850 | 卡方 0.7064，p=0.4006，阈值 0.001 | pass |
| 实验前平衡性 | 最大 `abs(SMD)` 0.04 | pass |
| 曝光完整性 | 两臂曝光率差 1.1pp | pass |
| 污染 | 跨组曝光 1.8% | pass |
| 重复企业 | 0.6% | pass |
| 数据血缘 | 订单表 T+1，报价表 T+0，已对账 | pass |

## 4. 读数

| 指标 | Control | Treatment | 绝对提升 | 相对提升 | 95% CI（绝对） | p |
|---|---:|---:|---:|---:|---|---:|
| Q2O（主） | 8.40% | 9.20% | +0.80pp | +9.52% | [+0.18pp, +1.42pp] | 0.0115 |
| 报价接受率 | 31.0% | 32.4% | +1.4pp | +4.52% | [−0.3pp, +3.1pp] | 0.10 |
| 净 GMV/企业 | ¥1,840 | ¥1,905 | +¥65 | +3.53% | [−¥12, +¥142] | 0.09 |
| 卖家报价率（护栏） | 78.0% | 71.9% | −6.1pp | −7.82% | [−7.4pp, −4.8pp] | <0.001 |
| 取消率（护栏） | 4.1% | 5.3% | +1.2pp | +29.3% | [+0.4pp, +2.0pp] | 0.003 |

**子群**：新买家 +15.1%，老买家 +6.8%，交互 p=0.04（未做多重比较校正，视为探索性）。

## 5. 解释

1. **主指标显著，但低于设计 MDE**：观测 +9.52%，设计 MDE 11%。CI 上限 16.91% 包含 MDE，说明“方向可信、幅度未达业务门槛”，不能直接说“达到预期”。
2. **护栏否决**：卖家报价率 −6.1pp，超过 −5pp 阈值；取消率 +1.2pp 虽未超 +2pp，但方向不利。主指标正向不能抵消供给侧伤害。
3. **子群是假设，不是结论**：新买家交互 p=0.04 未校正，且与“卖家报价率下降”冲突；不能据此直接定向新买家。
4. **业务判断**：4 小时承诺对部分卖家不可行，卖家选择不报价/延迟报价，短期买家转化上升，长期供给质量下降。

## 6. 决策

**迭代，不全量。**

- 修正卖家容量与激励：按卖家分层设置承诺时效，增加“可承诺”判断。
- 把卖家报价率设为 co-primary guardrail，阈值仍为 −5pp。
- 复测时保持企业级随机，增加卖家侧分层；不要在新买家定向，直到供给伤害消失。
- 灰度上限 10%，保留 5% holdout 观察 60/90 天复购与卖家留存。

## 8. 可复用经验

- **显著 ≠ 可全量**：要看效应是否达到 MDE/MBE，以及护栏是否被伤害。
- **护栏要在设计时就有否决权**：否则读数时会被“主指标显著”绑架。
- **样本量要先于故事**：旧案例的 6,200 家/臂撑不起 +0.8pp 的显著结论，这种数字不能进教学案例。
- **B2B 的供给侧是实验的一部分**：卖家报价率、履约能力、服务容量，往往才是长期约束。
